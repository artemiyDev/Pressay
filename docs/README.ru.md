# Pressay — руководство на русском

[English](README.en.md) · [Решение проблем](TROUBLESHOOTING.md) ·
[Статус тестирования](TESTING.md) · [Главная](../README.md)

**Press → say.** Pressay — локальная голосовая диктовка для Windows и macOS.
После загрузки выбранной модели в локальный кэш распознавание работает без
облачного API. Поддерживаются русский и английский языки.

## Возможности

- настраиваемые глобальные горячие клавиши Windows для push-to-talk и
  hands-free, а также фиксированные сочетания macOS beta, с предупреждением о
  конфликтах раскладки;
- локальное распознавание через faster-whisper;
- личный словарь и замены технических терминов;
- необязательные голосовые команды при включении настройки: «нажми Enter», «с новой строки» и «абзац»;
- необязательный голосовой режим локального перевода следующей RU/EN-диктовки
  на английский;
- проверка активного окна и редактируемого поля перед каждой вставкой;
- до 20 последних расшифровок только в памяти приложения до его закрытия;
- явное копирование без скрытой подмены clipboard при ошибках вставки;
- на Windows автовставка всё же обращается к буферу обмена для многострочного текста и символов вне BMP (эмодзи), восстанавливая прежнее содержимое — «Вставить последнюю» и «Скопировать» используют буфер всегда; на macOS автовставка и «Вставить последнюю» буфера не касаются, к нему обращается только «Скопировать»;
- при включённой истории буфера обмена Windows (Win+V) такой фрагмент остаётся в истории даже после того, как Pressay восстановил буфер, а при включённой синхронизации между устройствами — уходит в облако; отключить историю можно в **Параметры → Система → Буфер обмена**.

Режим «Русский» или «English» пропускает автоматическое определение языка и
может ускорить распознавание. Это подсказка распознавателю, а не перевод:
диктовка на другом языке может дать неточный текст.

Перевод — отдельный режим текущей сессии. Включите в настройках **Голосовое
переключение перевода на английский**, затем произнесите отдельной фразой
«переведи на английский» или “translate to English”. Для выключения скажите
«хватит переводить» или “stop translating”. Пока режим активен, в оверлее
записи отображается **→ EN**. Модель `turbo` перевод не поддерживает, поэтому
Pressay использует выбранную модель перевода `small`, `medium` или `large-v3`;
если её ещё нет в локальном кэше, она загрузится при первом использовании.

## Windows 11 — стабильная версия

Требования: Windows 11 x64, Python 3.11, работающий микрофон. NVIDIA GPU
необязательна: при наличии CUDA используется GPU, иначе включается CPU.

```powershell
git clone https://github.com/artemiyDev/Pressay.git
cd Pressay
.\scripts\install.ps1 -DesktopShortcut -EnableAutostart
```

Перед установкой или обновлением полностью завершите Pressay через меню в трее:
закрыть только окно настроек недостаточно. Установщик не изменяет приложение,
пока оно запущено.

Установщик без прав администратора:

- публикует версионную копию приложения в
  `%LOCALAPPDATA%\Pressay\app\<version>`;
- переключает маленький указатель `%LOCALAPPDATA%\Pressay\current` и
  устанавливает стабильный launcher `%LOCALAPPDATA%\Pressay\Pressay.ps1`;
- создаёт `%LOCALAPPDATA%\Pressay\venv`;
- устанавливает зависимости и загружает модель `turbo`;
- создаёт Pressay в меню «Пуск» и, по запросу, на рабочем столе;
- по флагу `-EnableAutostart` создаёт ярлык в Startup;
- запускает приложение в системном трее.

Ярлыки меню «Пуск», рабочего стола и автозапуска указывают на стабильный
launcher. Поэтому после успешной установки Windows-версия продолжает работать,
даже если клонированную папку переместить или удалить. Для будущего обновления
или обслуживания при необходимости снова получите исходный код Pressay. При
обновлении общий runtime используется повторно, а конфигурация, логи и общий
кэш моделей сохраняются вне версионной копии приложения.

Полезные варианты:

```powershell
.\scripts\install.ps1 -NoLaunch
.\scripts\install.ps1 -Model small
.\scripts\install.ps1 -SkipModel
.\scripts\doctor.ps1
.\scripts\test.ps1 -q
```

Горячие клавиши Windows (значения по умолчанию; настраиваются в окне Pressay,
группа «Горячие клавиши»):

| Действие | Клавиши по умолчанию |
|---|---|
| Диктовка при удержании | `Ctrl+Win` |
| Включить/выключить hands-free | `Ctrl+Win+Space` |
| Отмена | `Esc` |
| Вставить последнюю расшифровку | `Shift+Alt+Z` |
| Скопировать последнюю расшифровку | `Shift+Alt+X` |

Комбинация удержания выбирается из шести пар модификаторов (`ctrl`, `win`,
`shift`, `alt`). Клавиша переключения, «Вставить последнюю» и «Скопировать»
задаются текстом вида `модификатор+модификатор+клавиша` (например,
`shift+alt+z`): части через «+», модификаторы — `ctrl`, `win`, `shift`,
`alt`, обычная клавиша — буква, цифра, `space` или `f1`–`f12`. Слово `none`
отключает действие. Push-to-talk можно выключить — тогда запись включается и
выключается только сочетанием с клавишей переключения, без удержания.
Отмена (`Esc`) не настраивается.

Предупреждение о конфликтах: `Ctrl+Alt` на многих раскладках равносилен
AltGr и используется для ввода символов; `Ctrl+Shift` и `Shift+Alt` часто
переключают раскладку Windows. `Ctrl+Win` задействует системную клавишу Windows
и тоже может пересекаться с сочетаниями Windows или конкретного приложения.
Универсально бесконфликтной пары нет — выберите вариант, свободный в ваших
приложениях и раскладках.

## macOS 13+ — developer beta

Требования: Intel Mac или Apple Silicon, macOS 13+, Python 3.11. Эта версия
проверяется на GitHub-hosted Apple Silicon runner, но ещё не прошла ручной
аппаратный тест на реальном пользовательском Mac.

```bash
git clone https://github.com/artemiyDev/Pressay.git
cd Pressay
bash scripts/install-macos.sh
```

Приложение также запускается из текущей копии репозитория. Не перемещайте и не
удаляйте её после установки, пока не установите Pressay заново из нового пути.

По умолчанию устанавливается CPU-модель `small`: она разумнее для первого
запуска без CUDA. Faster-whisper/CTranslate2 на Mac не использует Metal/MPS.

Установщик:

- создаёт `~/Library/Application Support/Pressay/venv`;
- устанавливает PySide6, faster-whisper, sounddevice и PyObjC;
- загружает и прогревает модель `small` на CPU;
- создаёт `~/Applications/Pressay.app` с новым логотипом;
- не включает автозапуск без явного `--enable-autostart`.

```bash
bash scripts/install-macos.sh --enable-autostart
bash scripts/install-macos.sh --model medium
bash scripts/install-macos.sh --no-launch
bash scripts/doctor-macos.sh
bash scripts/test-macos.sh
```

### Разрешения macOS

Откройте **System Settings → Privacy & Security** и разрешите Pressay:

1. **Microphone** — запись речи;
2. **Accessibility** — проверка редактируемого поля и Unicode-ввод;
3. **Input Monitoring** — глобальные горячие клавиши.

После изменения Accessibility или Input Monitoring полностью закройте и снова
запустите Pressay. Если глобальные клавиши не запустились, Pressay откроет
окно даже при фоновом запуске и оставит в нём постоянное предупреждение.
Статус готовности модели не восстанавливает глобальные клавиши: выдайте
разрешения и перезапустите приложение. Если macOS показывает Python вместо
Pressay, разрешите Python из
`~/Library/Application Support/Pressay/venv/bin/python`. Подписанный `.dmg`
станет отдельным release-этапом.

Горячие клавиши macOS beta фиксированы. Pressay показывает их в таблице только
для чтения; редактор настраиваемых сочетаний Windows на macOS не показывается:

| Действие | Клавиши |
|---|---|
| Диктовка при удержании | `Control+Option` |
| Включить/выключить hands-free | `Control+Option+Space` |
| Отмена | `Esc` |
| Вставить последнюю расшифровку | `Control+Option+V` |
| Скопировать последнюю расшифровку | `Control+Option+C` |

## Удаление

Windows:

```powershell
.\scripts\uninstall.ps1
.\scripts\uninstall.ps1 -RemoveApp
.\scripts\uninstall.ps1 -RemoveRuntime
.\scripts\uninstall.ps1 -RemoveUserData
.\scripts\uninstall.ps1 -RemoveApp -RemoveRuntime -RemoveUserData
```

Без флагов скрипт удаляет только принадлежащие Pressay ярлыки из меню «Пуск»,
рабочего стола и автозапуска. Установленное приложение, runtime, конфигурация,
логи и модели сохраняются. Перед использованием любого из флагов удаления ниже
полностью завершите Pressay через меню в трее.

`-RemoveApp` удаляет версионные копии приложения, указатель `current`, launcher
и иконку. `-RemoveRuntime` удаляет общий virtual environment Pressay.
`-RemoveUserData` безвозвратно удаляет конфигурацию и логи. Флаги можно
комбинировать. Общий кэш моделей Hugging Face этот скрипт не удаляет.

macOS:

```bash
bash scripts/uninstall-macos.sh
bash scripts/uninstall-macos.sh --remove-runtime
bash scripts/uninstall-macos.sh --remove-user-data
```

Скрипт удаления macOS также сохраняет конфигурацию без явного флага user data и
никогда не удаляет общий кэш моделей Hugging Face.

## Где хранятся данные

| Данные | Windows | macOS |
|---|---|---|
| Установленное приложение | `%LOCALAPPDATA%\Pressay\app\<version>` | Копия репозитория (developer beta) |
| Указатель активной версии | `%LOCALAPPDATA%\Pressay\current` | — |
| Стабильный launcher | `%LOCALAPPDATA%\Pressay\Pressay.ps1` | `~/Applications/Pressay.app` (зависит от репозитория) |
| Конфигурация | `%LOCALAPPDATA%\Pressay\config.json` | `~/Library/Application Support/Pressay/config.json` |
| Runtime | `%LOCALAPPDATA%\Pressay\venv` | `~/Library/Application Support/Pressay/venv` |
| Логи | `%LOCALAPPDATA%\Pressay\pressay.log` | `~/Library/Application Support/Pressay/pressay.log` |
| Модели | Hugging Face cache | Hugging Face cache |

Логи не содержат текста расшифровок, аудио и заголовков окон.

Если что-то не работает, начните с
[двуязычного руководства по диагностике](TROUBLESHOOTING.md).
